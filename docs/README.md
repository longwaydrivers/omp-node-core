# `@omp-node/core` documentation

Start with [Getting started](getting-started.md), then use the [API reference](api.md), [event catalogue](events.md), and [type reference](types.md).

The reference is organized around the public exports from `src/main.ts`. The names and signatures in `dist/bundle.d.ts` remain authoritative; these pages explain how the values behave at runtime and how the pieces fit together.
